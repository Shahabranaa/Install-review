Product Requirements Document (PRD)

1. Overview

I work as an Offshore Wind Project / Site Operations Manager.
I want to build an application that manages workforce compliance, onboarding, and mobilisation readiness for offshore projects.

The purpose of the app is to ensure that every worker assigned to a site is fully compliant with all certification and training requirements before mobilisation, reducing delays, failed mobilisations, and compliance risks.

---

2. Core Concept

The system is a Mobilisation Readiness Engine.

Each worker:

- Has a profile
- Has certifications with expiry dates
- Is assigned to roles and sites

The system determines:

«Whether a worker is “Ready to Mobilise” based on required certifications.»

---

3. Key Features

1. Worker Management

- Create and manage worker profiles
- Assign roles to workers
- Store basic details (name, company, role, WINDA ID)

---

2. Certification Management

- Create a master list of certifications (e.g. GWO BST, Medical, BTT)
- For each worker:
  - Upload certification files (PDF/image)
  - Store:
    - Date achieved
    - Expiry date
    - Verification status

---

3. Requirement Engine (Critical Feature)

The system must support certification requirements at 3 levels:

- Site-level requirements
- Role-level requirements
- User-specific requirements (overrides)

The system combines all three to determine required certifications per worker.

---

4. Compliance Logic

For each worker assigned to a site:

- Check all required certifications
- Validate:
  - Exists
  - Not expired
  - Verified

Output status:

- ✅ Ready
- ⚠️ Expiring Soon
- ❌ Not Compliant

---

5. Dashboard & Visibility

Provide clear visibility of workforce compliance:

- % of workforce ready
- List of:
  - Missing certifications
  - Expiring soon (e.g. within 30 days)
- Filter by:
  - Site
  - Role
  - Company

---

6. Alerts & Notifications

- Notify users/admins when:
  - Certifications are expiring (e.g. 30 / 14 / 7 days)
- Notifications via:
  - Email (v1 minimum)

---

7. Site Assignment & Pre-Mobilisation Check

- Assign workers to a site
- System automatically evaluates compliance
- Show:
  - Missing certifications before mobilisation

---

4. Data Model (High-Level)

Entities required:

- Users (workers)
- Roles
- Sites
- Certifications
- User Certifications (with expiry + files)
- Site Requirements
- Role Requirements
- User Requirements

---

5. Business Rules

- A worker is NOT ready if any required certification is:
  
  - Missing
  - Expired
  - Not verified

- Certifications expiring within a defined window (e.g. 7–14 days) can be treated as invalid

- Requirements must be dynamic (not hardcoded to users)

---

6. v1 Scope (Important)

Focus only on:

- Worker profiles
- Certification tracking
- Requirement engine
- Compliance status

Do NOT include:

- AI features
- Complex integrations
- Payroll or HR features

---

7. Future Enhancements (Do Not Build Yet)

- WINDA verification integration
- AI document recognition (auto-read certificates)
- Mobile app
- Integration with project planning tools
- Linking certifications to specific assets / tasks

---

8. Success Criteria

The system is successful if:

- A manager can instantly see if a worker is ready for a specific site
- Compliance issues are identified before mobilisation
- Certification tracking is centralized and reliable

---

9. Summary

This is not a general HR tool.
This is a compliance and mobilisation decision system for offshore workforce management.

The priority is:

- Accuracy
- Simplicity
- Speed of checking compliance
