Smart-Projex DPR Bot
Features & Format Guide


What the Bot Can Do
 Smart Header Parsing
The bot reads your DPR header and automatically extracts:
Team Name — identifies which team the report belongs to.
Starting Location — applies it to all activities until a new location appears.
Shift Start & End Time — sets the shift window and validates all activities fall within it.
Shift Date — locks the date for the entire report. Use DD-MM-YYYY.
More Features
 Location Cascading
You only need to provide the location once in the header. The bot automatically carries it forward to every activity — no need to repeat it on every line. When an activity says Transfer to BLP55, the bot picks up BLP55 as the new location and cascades it to the next activities.

Note: Please write the Location Name
 Gap Detection
If there is a missing time window between two activities (e.g. one ends at 13:20 and the next starts at 14:20), the bot flags the 1-hour gap and asks you to fill it before the report can be submitted.
 Overlap Detection
If two activities have conflicting times, the bot detects the overlap and highlights exactly which activities clash — so you can fix them quickly.
 Midnight Crossover Handling
Night shifts that cross midnight (e.g. 17:30 - 05:30) are handled automatically. The bot knows that 00:00 comes after 23:30 and keeps the date consistent throughout.
 Activity Merging
If two activities need to be combined into one, simply say Merge activity 3 and 4. The bot merges them in a single step and renumbers everything automatically.
 Add, Remove & Modify Activities
Add: Add activity: 18:00-19:00 FO prep, location OSS. Insert before activity 4.
Remove: Remove activity 5 — the bot deletes it and renumbers.
Modify: Change activity 4 end time to 21:10 — only that one activity is changed, nothing else.
 Automatic Renumbering
After any merge, add, or delete, the bot automatically renumbers all activities so the list stays clean and sequential.
 One-Tap Export to Google Sheets
Once everything looks correct, reply Approved and the bot logs the finalised timesheet directly to Google Sheets.
