01 — PRODUCT OVERVIEW
Product Name
Installation Image Review App (working name)
Problem
Installation teams capture hundreds of images, but:
No consistent quality control
Time wasted manually reviewing images
Hard to prove installation completion
Document generation is slow and manual
Solution
A web-based review system that:
pulls images from AppSheet (via Google Drive + Sheets)
uses AI to review images and flag issues
groups images by installation phase
helps admins decide if a phase is complete
generates documents once completion is confirmed
Users
Admin reviewers (primary)
QA teams
Project managers
MVP Goal
Enable admins to:
see all images by project/site/phase
review AI-flagged issues
approve or reject phase completion
generate a simple completion/report document
Success Criteria (MVP)
Images automatically appear in dashboard
AI flags obvious issues reliably
Admin can review and override quickly
Phase completion status is visible and accurate
A report can be generated from approved data
02 — MVP SCOPE
IN SCOPE (must work for launch)
Image ingestion from Google Drive + Sheets

03 — CORE WORKFLOWS
Workflow 1 — Image Ingestion
Technician captures image in AppSheet
Image stored in Google Drive
Metadata written to Google Sheets
System detects new image record
Image appears in review dashboard

Workflow 2 — AI Image Review
New image is sent to AI review service
AI analyzes image
AI returns:
issue flags
confidence score
suggested status
Results stored against image

Workflow 3 — Admin Review
Admin opens dashboard
Filters by project / site / phase
Sees:
images
AI flags
status indicators
Admin can:
approve image
reject image
override AI decision

Workflow 4 — Phase Evaluation
System groups images by phase
System checks:
required images present
AI results
issue severity
System assigns phase status:
Complete
Incomplete
Needs Review

Workflow 5 — Final Approval + Document
Admin reviews phase
Admin approves completion
System unlocks document generation
Document generated using:
images
metadata
results
Document stored and linked to phase

04 — BUSINESS RULES
AI Responsibilities
AI SHOULD:
detect image quality issues
detect missing or unclear evidence
identify possible installation defects
flag duplicates or wrong assets
assign confidence score
suggest status
AI SHOULD NOT:
approve completion
make final decisions
override human input

Issue Severity Levels
Critical (blocks completion)
missing component
clear installation defect
wrong asset/location
completely unusable image
Warning
blurry image
poor angle
partial visibility
Info
duplicate image
minor quality issue

Phase Completion Logic
A phase can be AUTO-COMPLETE only if:
all required images are present
no critical issues
AI confidence above threshold
metadata matches expected values

MUST GO TO HUMAN REVIEW if:
missing images
any critical issue
low confidence
conflicting results

Human Actions
approve phase
reject phase
override AI flags
mark issues as accepted

Document Generation Rules
Document can ONLY be generated if:
phase is approved
no unresolved critical issues
all required data exists
approval is logged
