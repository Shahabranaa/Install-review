---
name: DPR team setup is optional
description: The product rule governing daily team selection and the core Capture and Clarify workflows.
---

Daily Team Setup is optional. It can narrow the team list shown in Capture when an administrator has saved a selection for a date, but an empty or missing selection must never prevent users from opening, reviewing, entering, locking, or clarifying timesheets.

**Why:** Team setup supports planning and expected-team reporting, whereas Capture and Clarify are the core daily workflows. Users need both workflows to work before an administrator completes setup.

**How to apply:** Do not add empty-team setup gates to Capture or Clarify. Treat saved daily selections as an optional display/filtering constraint only; preserve unassigned-entry handling and normal validation.
